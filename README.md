# Sreelekha Royal Real Estate

Enhanced frontend real-estate website with the supplied owner image.

## Run
Open the extracted folder in VS Code and use Live Server on `index.html`.

## Main features
- Owner & Founder hero image using the supplied photo
- Sreelekha Royal branding
- Property search, filters and sorting
- Property details and similar properties
- Favorites saved in localStorage
- Agents directory
- Services
- Customer reviews
- FAQ
- Contact/enquiry form
- Home loan EMI calculator
- Login/register demo
- User dashboard
- Admin dashboard
- List property form
- Responsive mobile layout
